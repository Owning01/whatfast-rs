Un cliente de WhatsApp liviano y con tus datos en tu compu.

Whatfast no trae un navegador adentro. Son dos programas chicos: uno dibuja la pantalla y el otro se ocupa de la conexión. Por eso abre rápido y no te come la memoria del equipo.

Dibuja directo, sin navegador

La ventana la dibuja el sistema con la placa de video, igual que un juego. No hay un navegador escondido adentro: no hay página que cargar ni JavaScript que bajar. Por eso la lista de chats se desliza suelta, aunque tengas miles de conversaciones.

Preguntas frecuentes sobre Whatfast

Lo que más se pregunta antes de instalar un cliente de WhatsApp para Windows o Linux.

¿Qué es Whatfast?

Whatfast es un cliente de WhatsApp de escritorio, nativo y de código abierto. Se vincula con el código QR de WhatsApp como cualquier otro dispositivo y muestra tus chats en una ventana propia, sin abrir un navegador.

¿En qué se diferencia de WhatsApp Web?

WhatsApp Web es una página dentro del navegador: necesita Chrome o Edge, descarga JavaScript y ocupa la memoria de un motor web. Whatfast dibuja la interfaz directamente en Windows o Linux. Medido en Windows 11, el conjunto completo usa 92,3 MB de RAM frente a los 432 MB del cliente anterior con WebView2.

¿Cómo se instala y se vincula?

Descargá el instalador de Windows o el paquete de Linux, abrí Whatfast y escaneá el código QR desde WhatsApp en el teléfono: Ajustes, Dispositivos vinculados, Vincular un dispositivo. No hay que crear ninguna cuenta.

¿Dónde se guardan mis mensajes?

En tu computadora. El historial, las llaves y los archivos viven en un archivo local del perfil de Whatfast. No pasan por servidores propios: la conexión va directo a WhatsApp, igual que en el teléfono.

¿Es gratis?

Sí. Whatfast es software libre y el código está en GitHub. Podés leerlo, compilarlo y reportar problemas.

¿Sirve para llamadas y videollamadas?

Sí: llamadas de voz y videollamadas con la cámara del equipo, además de chats, grupos, canales, estados y stickers.

¿Qué sistemas operativos soporta?

Windows 10 y 11 de 64 bits, y Linux x86_64.

¿Reemplaza a la app oficial de WhatsApp?

No. Es un cliente de escritorio más chico, más rápido y con los datos en tu disco. El README del repositorio lista lo que ya funciona y lo que todavía falta.

¿Se conecta con agentes de IA?

Sí. Whatfast trae un servidor MCP: un clic lo registra en Claude Code, Codex, OpenCode, Cursor, Claude Desktop, VS Code, Antigravity, Pi o Hermes. De entrada el agente solo lee; para escribir o mandar mensajes hay que darle permiso.

Comienza con un solo comando

Instala el binario oficial con PowerShell o compila el repositorio con Cargo en cuestión de minutos.

# Descargar la última versión y descomprimirla en %LOCALAPPDATA%\Programs\Whatfast $zip = "$env:TEMP\whatfast.zip" Invoke-WebRequest https://github.com/Owning01/whatfast-rs/releases/latest/download/whatfast-windows.zip -OutFile $zip Expand-Archive $zip -DestinationPath "$env:LOCALAPPDATA\Programs\Whatfast" -Force
